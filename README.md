# 🚗 RouteLine — Car Rental Management System

## Project Objective

The objective of this project is to develop a modern and responsive **Car Rental Management System** that allows users to browse available cars, search and filter vehicles, view detailed car information, and book cars online. This project demonstrates frontend development skills, responsive web design, JavaScript functionality, form validation, and real-world project structure.

---

## Project Overview

**RouteLine** is a modern, responsive car rental website built using **HTML, CSS, and JavaScript** without any external frameworks or build tools. It provides an easy-to-use interface where users can explore available cars, view rental details, search and filter vehicles, and submit booking requests.

The project uses a static JavaScript dataset for car information, while user accounts and booking records are stored locally using the browser's **LocalStorage**.

## How to Run the Project

No installation is required.

### Option 1: Open Directly

1. Download or clone the repository.
2. Open the project folder.
3. Double-click **index.html** to launch the website.

### Option 2: Run Using a Local Server (Recommended)

```bash
cd car-rental
python3 -m http.server 8080
```

Then open:

```
http://localhost:8080
```

## Design Highlights

The project follows a modern automotive theme using an **asphalt and amber color palette** with a clean dashboard-inspired interface. Typography is designed using **Oswald** for headings, **Inter** for body text, and **JetBrains Mono** for specifications and pricing to provide a professional user experience.
